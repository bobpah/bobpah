# EA Finance Bot: บันทึกรายรับรายจ่ายผ่าน LINE

บอท LINE OA สำหรับทีมเพจ EA ใช้บันทึกรายรับรายจ่าย ทีมงานส่งรูปสลิปหรือใบเสร็จเข้าห้องไลน์ แล้ว AI จะอ่านยอดให้ แอดมินกดอนุมัติแล้วรายการจะถูกบันทึกลง Google Sheet ดูภาพรวมได้ที่แดชบอร์ด

**ใช้ได้ฟรีทั้งหมด:** Google Apps Script + Google Sheet + Gemini API (ใช้แบบฟรี) + LINE OA (แพ็กเกจฟรี)

```
ทีมส่งสลิปในกลุ่มไลน์ → Apps Script (webhook) → Gemini อ่านสลิป
      → บอทตอบเป็นการ์ด [✅ อนุมัติ] [❌ ปฏิเสธ] [🏷 เปลี่ยนหมวด] [🔁 รับ/จ่าย]
      → แอดมินกดอนุมัติ → บันทึกลง Google Sheet → แดชบอร์ด / สรุปอัตโนมัติ
```

## ความสามารถ

| ฟีเจอร์ | รายละเอียด |
|---|---|
| 📷 อ่านสลิป | อ่านได้ทั้งสลิปโอนเงินทุกธนาคาร, PromptPay, ใบเสร็จค่าแอด Facebook/Google/TikTok (รวมยอด USD) และไฟล์ PDF |
| 🔀 แยกรับ/จ่ายอัตโนมัติ | ดูจากชื่อบัญชีของธุรกิจ (`OWN_ACCOUNT_KEYWORDS`) ถ้าแยกผิดกดปุ่ม 🔁 สลับได้ |
| 🏷 จัดหมวดอัตโนมัติ | มีหมวดตั้งต้นที่เหมาะกับเพจ EA (ค่าโฆษณา, VPS, ซอฟต์แวร์, ขาย EA, VIP, IB ฯลฯ) แก้ไขได้ที่ชีต Categories |
| ✅ ขั้นตอนอนุมัติ | ทีมงานส่งสลิปได้ทุกคน แต่กดอนุมัติได้เฉพาะแอดมิน (ตั้งค่าได้) |
| ⚠️ กันสลิปซ้ำ | เตือนเมื่อเลขอ้างอิง หรือยอดเงินกับเวลาซ้ำกับรายการเดิม |
| ✍️ บันทึกเอง | พิมพ์ได้ เช่น `-500 ค่าแอด`, `+1500 ขาย EA`, `-$50 facebook`, `-900 #VPS @บัตรเครดิต` |
| 💱 สกุลเงิน USD | แปลงเป็นบาทตามอัตรา `FX_USD` |
| 👛 หลายกระเป๋า | ระบุได้ด้วย `@ชื่อกระเป๋า` แดชบอร์ดแสดงยอดแยกตามกระเป๋า |
| 🎯 งบประมาณ | `ตั้งงบ ค่าโฆษณา 20000` ระบบจะเตือนเมื่อใช้ถึง 80% และเมื่อเกิน 100% |
| 📊 แดชบอร์ด | ยอดรับ/จ่าย/กำไร, กราฟรายวัน, สัดส่วนรายหมวด, แนวโน้ม 6 เดือน, งบประมาณ และรายการล่าสุด (เปิดในไลน์ได้ รองรับมือถือและโหมดมืด) |
| 🌙 สรุปอัตโนมัติ | ส่งสรุปเข้ากลุ่มทุกวัน 21:00 และปิดยอดทุกวันที่ 1 ของเดือน |
| 📁 Export | `export` หรือ `export 2026-09` สร้างไฟล์ Google Sheet ของเดือนนั้น พร้อมแท็บสรุป |
| 📱 Rich Menu | 6 ปุ่ม: ส่งสลิป, บันทึกเอง, แดชบอร์ด, สรุปยอด, รออนุมัติ, วิธีใช้ |

## วิธีติดตั้ง (ประมาณ 20–30 นาที)

> ⚠️ **ทำก่อน:** ถ้ารหัสผ่าน Gmail เคยถูกส่งต่อให้ใคร ให้เปลี่ยนรหัสผ่านและเปิด 2-Step Verification ก่อน ระบบนี้ไม่ต้องใช้รหัสผ่าน Gmail เลย

### 1) สร้าง Google Sheet และวางโค้ด
1. ล็อกอินด้วย Gmail ของเพจ แล้วสร้าง Google Sheet ใหม่ ตั้งชื่อเช่น `EA Finance`
2. ไปที่เมนู **Extensions (ส่วนขยาย) → Apps Script**
3. ไปที่ ⚙️ **Project Settings** แล้วติ๊ก **Show "appsscript.json" manifest file in editor**
4. คัดลอกโค้ดจากโฟลเดอร์ **`dist/`** ไปวาง ซึ่งมีแค่ 3 ไฟล์:
   - `dist/Code.gs`: เลือกทั้งหมดในไฟล์ `Code.gs` เดิมของ Apps Script แล้ววางทับ (เป็นไฟล์รวมโค้ดทั้งหมดแล้ว)
   - `dist/Dashboard.html`: กด ➕ → HTML ตั้งชื่อ `Dashboard` แล้ววาง
   - `dist/appsscript.json`: วางทับของเดิม (ใช้ตั้งเขตเวลาเป็นเวลาไทย)
   - วิธีเปิดไฟล์บน GitHub ให้คัดลอกง่าย: เข้าไปที่ไฟล์ แล้วกดปุ่ม **Raw** หรือปุ่ม 📋 Copy
5. กด 💾 Save

> นักพัฒนา: โค้ดต้นฉบับแยกไฟล์อยู่ใน `apps-script/` แก้แล้วรัน `./scripts/build.sh` เพื่อสร้าง `dist/` ใหม่

### ทางเลือกสำหรับนักพัฒนา: ใช้ clasp ไม่ต้องคัดลอกโค้ด

ใช้วิธีนี้หลังสร้าง Google Sheet และเปิด Apps Script แบบ bound กับชีตแล้ว:

1. ติดตั้ง clasp และล็อกอินด้วยบัญชี Google เดียวกับเจ้าของชีต
   ```bash
   npm install -g @google/clasp
   clasp login
   ```
2. ใน Apps Script ไปที่ **Project Settings** แล้วคัดลอก **Script ID**
3. ที่โฟลเดอร์รากของ repo สร้างไฟล์ config จริงจากตัวอย่าง แล้วใส่ Script ID:
   ```powershell
   Copy-Item .clasp.json.example .clasp.json
   notepad .clasp.json
   ```
   ค่า `rootDir: "dist"` หมายถึง clasp จะ push เฉพาะไฟล์รวมใน `dist/`
4. Build, ทดสอบ และ push:
   ```bash
   ./scripts/build.sh
   node tests/simulate.js
   SRC_DIR=dist node tests/simulate.js
   clasp push
   ```
   บน Windows ให้รัน `./scripts/build.sh` ใน Git Bash/WSL หรือใช้ `bash scripts/build.sh` ใน PowerShell
5. ถ้าต้องการอัปเดต Web app deployment เดิม ให้ดูรายการ deployment แล้ว redeploy ด้วยเวอร์ชันล่าสุด:
   ```bash
   clasp deployments
   clasp deploy --deploymentId <DEPLOYMENT_ID> --description "อธิบายการเปลี่ยนแปลง"
   ```
6. ครั้งแรกยังต้องเข้า Apps Script เพื่อรัน `setup()` และอนุญาตสิทธิ์ จากนั้น deploy Web app ตามขั้นตอนที่ 5 ด้านล่าง

ไฟล์ `.clasp.json` และ `.clasprc.json` ถูกใส่ไว้ใน `.gitignore` แล้ว ห้าม commit หรือส่งต่อ `.clasprc.json` เพราะเป็น credential ของ clasp การ push จะอัปเดต source ใน Apps Script แต่ไม่ deploy เวอร์ชันใหม่ให้อัตโนมัติ ให้ใช้คำสั่ง `clasp deploy` ด้านบน หรือกด **Deploy → Manage deployments → New version → Deploy** เอง

### 2) ติดตั้งชีต
1. กลับไปที่ Google Sheet แล้วรีเฟรชหน้า จะเห็นเมนู **EA Finance**
2. กด **EA Finance → 1) ติดตั้ง / ซ่อมชีต** แล้วกดอนุญาตสิทธิ์ (Advanced → Go to … (unsafe) เป็นเรื่องปกติของสคริปต์ที่เขียนเอง)
3. ระบบจะสร้างชีต `Transactions`, `Categories`, `Users`, `Config`, `Log` และแสดง **รหัสแอดมิน** ให้จดไว้

### 3) ขอ Gemini API Key (ฟรี)
1. เปิด https://aistudio.google.com/apikey แล้วกด **Create API key**
2. นำไปวางในชีต `Config` ช่อง `GEMINI_API_KEY`

### 4) ตั้งค่า LINE
1. เปิด https://developers.line.biz/console/ แล้วล็อกอิน → เลือก Provider → Channel ของ OA (ประเภท Messaging API)
   - ถ้ายังไม่มี ให้ไปที่ LINE OA Manager → ตั้งค่า → Messaging API → **เปิดใช้งาน**
2. แท็บ **Basic settings** → คัดลอก **Channel ID** และ **Channel secret** ไปวางที่ `Config` ช่อง `LINE_CHANNEL_ID` และ `LINE_CHANNEL_SECRET` ระบบจะออก token ให้เองและต่ออายุอัตโนมัติ (หรือจะออก long-lived token แล้ววางที่ `LINE_CHANNEL_ACCESS_TOKEN` แทนก็ได้)
3. ใน **LINE OA Manager**:
   - ไปที่ ตั้งค่าการตอบกลับ: เปิด **Webhook**, ปิด **ข้อความตอบกลับอัตโนมัติ** (สำคัญมาก ไม่เช่นนั้น LINE จะส่งข้อความสำเร็จรูปแทนบอท), ปิด **ข้อความทักทาย** (ถ้าไม่ต้องการ)
   - ไปที่ ตั้งค่าบัญชี: เปิด **อนุญาตให้บัญชีเข้าร่วมแชทกลุ่ม**

### 5) Deploy เป็น Web App
1. ใน Apps Script กด **Deploy → New deployment** → ⚙️ เลือก **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
2. กด Deploy แล้วคัดลอก URL ที่ลงท้ายด้วย `/exec` ไปวางที่ `Config` ช่อง `WEB_APP_URL`
3. ใน Google Sheet กด **EA Finance → แสดงลิงก์ Webhook / Dashboard**
4. นำ **Webhook URL** (มี `?key=...` ต่อท้าย) ไปวางที่ LINE Developers → Messaging API → **Webhook URL** แล้วเปิด **Use webhook**
    - กด Verify ควรขึ้น Success ถ้าไม่ขึ้น ให้ตรวจว่า URL ลงท้าย /exec และมี ?key=... ครบ
5. กด **EA Finance → 2) ทดสอบการเชื่อมต่อ** ควรเห็น ✅ ทั้ง LINE และ Gemini

### 6) ใช้งานในกลุ่มทีม
1. เชิญ LINE OA เข้ากลุ่มทีมงาน (บอทจะจำห้องนี้ไว้สำหรับส่งสรุปอัตโนมัติ)
2. เจ้าของหรือหัวหน้าพิมพ์ `แอดมิน <รหัส>` (รหัสอยู่ในชีต Config) เพื่อเป็นแอดมิน
3. ถ้าต้องการเปลี่ยนห้องที่รับสรุป ให้แอดมินพิมพ์ `ตั้งกลุ่มนี้` ในห้องนั้น
4. ใส่ชื่อบัญชีธนาคารหรือเลขท้ายบัญชีของธุรกิจในช่อง `OWN_ACCOUNT_KEYWORDS` เช่น `นายสมชาย ใจดี, 123-4` ระบบจะใช้แยกเงินเข้ากับเงินออกได้แม่นขึ้น
5. กด **EA Finance → 3) ตั้งเวลาสรุปอัตโนมัติ**

### 7) Rich Menu
1. ดาวน์โหลด `richmenu/richmenu.png` แล้วอัปโหลดขึ้น Google Drive ของบัญชีเดียวกัน (ไว้ที่ไหนก็ได้)
2. กด **EA Finance → 4) สร้าง Rich Menu**
3. เปิดแชท 1:1 กับ OA จะเห็นเมนูด้านล่าง
   - หมายเหตุ: **LINE ไม่แสดง Rich Menu ในแชทกลุ่ม** ในกลุ่มให้ส่งสลิปหรือพิมพ์คำสั่งแทน ส่วนเมนูใช้ได้ในแชท 1:1

### เมื่อแก้โค้ดภายหลัง
กด **Deploy → Manage deployments → ✏️ → Version: New version → Deploy** แบบนี้ URL จะยังเป็นอันเดิม ไม่ต้องไปเปลี่ยน webhook ใหม่

## ชีต Config ที่ควรรู้

| key | ความหมาย |
|---|---|
| `APPROVE_MODE` | `admin` = เฉพาะแอดมินอนุมัติได้ / `anyone` = ทุกคนอนุมัติได้ |
| `OWN_ACCOUNT_KEYWORDS` | ชื่อหรือเลขบัญชีของธุรกิจ ใช้แยกรับ/จ่าย |
| `FX_USD` | อัตราแลก USD เป็นบาท (เพิ่ม `FX_EUR` ฯลฯ เองได้) |
| `DAILY_SUMMARY` / `DAILY_SUMMARY_HOUR` | เปิดหรือปิดการสรุปรายวัน และเวลาที่ส่ง |
| `DASHBOARD_KEY` | รหัสในลิงก์แดชบอร์ด ถ้าลิงก์หลุดให้เปลี่ยนค่านี้ |
| `GEMINI_MODEL` | ค่าเริ่มต้นคือ `gemini-flash-latest` ซึ่งเป็น alias ของ Flash รุ่นล่าสุด ถ้าต้องการ pin รุ่นให้ใช้ `gemini-3.8-flash` หรือ `gemini-3.5-flash-lite` |

## ข้อจำกัดของแพ็กเกจฟรีที่ควรรู้

- **LINE OA ฟรี:** การตอบกลับ (reply) ไม่จำกัด แต่ **push** (สรุปอัตโนมัติ) มีโควตาต่อเดือน และในกลุ่มนับตามจำนวนสมาชิก บอทจึงส่งสรุปรายวันเฉพาะวันที่มีรายการ ถ้าโควตาไม่พอให้ตั้ง `DAILY_SUMMARY` เป็น `off` แล้วพิมพ์ `สรุป` เอาเองแทน
- **Gemini ฟรี:** จำกัดจำนวนครั้งต่อนาทีและต่อวัน (เพียงพอสำหรับวันละหลายสิบสลิป) ข้อมูลที่ส่งผ่าน API แบบฟรีอาจถูก Google นำไปใช้ปรับปรุงบริการ
- **ระบบไม่ได้ตรวจสลิปปลอมกับธนาคาร** AI แค่อ่านข้อมูลจากรูป ก่อนอนุมัติรายรับยอดสูง แอดมินควรเช็กยอดในแอปธนาคารก่อน (ระบบช่วยเตือนสลิปซ้ำให้แล้ว) ถ้าต้องการตรวจสลิปจริงกับธนาคาร สามารถต่อ API แบบเสียเงิน (SlipOK, EasySlip) เพิ่มทีหลังได้
- **Apps Script ตรวจลายเซ็น LINE ไม่ได้** เพราะอ่าน header ไม่ได้ ระบบจึงใช้รหัสลับ `?key=` ใน webhook URL แทน ห้ามเผยแพร่ลิงก์นี้
- โทเคนต่าง ๆ เก็บอยู่ในชีต `Config` อย่าแชร์สิทธิ์แก้ไขชีตให้คนนอก
